# Godot Learning Path（前端 → Godot 6 月計畫）

從 Vue / Angular 前端轉 Godot 4 的 6 個月學習與 portfolio 規劃。配套 [DiceFateSurvivor](https://github.com/asd23353934/dice-fate-survivor) 專案做為產出目標。

## 背景

- **起點**：Vue + Angular 前端 / 0 Godot 經驗
- **投入**：兼職 10-20 hr/week
- **時程**：6 個月（26 週）
- **產出**：可上 itch.io 的 DFS portfolio MVP + Live2D demo + 履歷
